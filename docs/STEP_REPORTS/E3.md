## 4. RED then GREEN Discipline & Implementation Summary

### 4.1 RED Phase Evidence
In Section 47 (`Section 47: Quality Policy & Compression Suite Tests`), three concrete failure modes were observed and recorded:

1. **RED 1 (Catalog Completeness Gate)**:
   ```
   --- Section 47: Quality Policy & Compression Suite Tests ---
     ✗ FAIL: 47.1 Every registered action in catalog has a declared quality class in QualityPolicy table - Missing quality classes for 1 actions: ["pdf.merge"]
   ```
   **Cause**: `pdf.merge` was registered in `FormatRegistry` but omitted from the initial mapping dictionary.
   **Fix**: Added `"pdf.merge": .lossless` to `QualityPolicy.defaultActionQualityClasses`.

2. **RED 2 (Archive Compression Test Invocations)**:
   ```
     ✗ FAIL: 47.6 Archive lossless compression extracts 100% identical file content
   ```
   **Cause**: The test invoked `ditto` with `--keepParent` on a single file inside a temporary directory, extracting nested parent paths rather than preserving root directory structure as done in `FormatRegistry.swift` (`--sequesterRsrc`).
   **Fix**: Aligned test invocation with production `archiveCreateZipAction` (`--sequesterRsrc`), verifying bit-for-bit file hash equality after archive extraction.

3. **RED 3 (Location Metadata Stripping Tool Execution)**:
   ```
     ✗ FAIL: 47.8 Location data stripping switch produces clean output with zero GPS metadata
   ```
   **Cause**: Test initially attempted to run `sips -d allxml` on PNG files, which fails with Error 13 on macOS image subsystem.
   **Fix**: Used the production metadata engine `exiftool` (`["-gps:all=", "-o", cleanOut.path, "--", sampleImg.path]`), confirming zero GPS tags in output and preserving image bit-streams.

### 4.2 GREEN Phase Implementation
1. **`PastaCore/QualityPolicy.swift`**:
   - Implemented `QualityClass` enum (`.lossless`, `.copy`, `.visuallyLossless`, `.lossy`) with `displayName` and `isLossless` properties.
   - Implemented `QualityPolicy` containing `defaultActionQualityClasses` table mapping all 111 registered action IDs in the catalog to their honest quality guarantees.
   - Implemented `effectiveQualityClass(for:parameters:)` handling parameter overrides (e.g. video compression presets, audio compression, lossy PDF options, and image compression toggles).
2. **`PastaCore/ConversionAction.swift`**:
   - Added `declaredQualityClass: QualityClass?` and computed property `qualityClass: QualityClass` on `ConversionAction`.
3. **`PastaCore/FormatRegistry.swift`**:
   - Updated `allRegisteredActions()` to enumerate all registered formats including subtitles (`.srt`, `.vtt`), code scripts (`.swift`), generic files (`.bin`), and directory actions.
4. **`PastaCore/PastaCLI.swift`**:
   - Added Quality Class column to `pasta list-actions --all --markdown`.
   - Added Quality Class tag `[\(a.qualityClass.displayName)]` to text output in `pasta list-actions`.
5. **`PastaTests/main.swift` (Section 47)**:
   - `47.1`: Gate test asserting every registered action in catalog has a declared quality class in `QualityPolicy` and non-empty `ConversionAction.qualityClass`.
   - `47.2`: Video quality policy verification: `video.to.mov` and `video.to.mkv` verified as `.copy`, `video.to.mp4` verified as `.visuallyLossless`, `video.compress` verified as `.lossy` (never labeled lossless).
   - `47.3`: Image lossless equality proof: decodes both original and optimized PNG, comparing raw 32-bit RGBA pixel buffers (including alpha channel) for 100% bit identity.
   - `47.4`: Audio lossless PCM equality proof: roundtrips WAV <-> FLAC using ffmpeg, decoding raw 16-bit stereo PCM streams (`-f s16le`) and verifying 100% byte equality (`dataA == dataB`).
   - `47.5`: PDF structure-level lossless proof: optimizes sample PDF via `qpdf` linearize/recompress-flate, renders both pages via CoreGraphics `CGPDFDocument` / `CGContext`, and verifies 100% identical pixel buffer.
   - `47.6`: Archive lossless extraction proof: compresses and extracts files using `ditto`, verifying 100% byte equality between original and extracted file data.
   - `47.7`: Image resizing logic: validates aspect-ratio preserving long-edge downscaling.
   - `47.8`: Metadata location stripping: validates GPS metadata removal switch using `exiftool -gps:all=`.
