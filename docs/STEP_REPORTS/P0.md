### 4.2 Assertion Audit & Restorations (RED then GREEN)
Audited all diffs across Step B1 and B2 commits (`aab3c84`, `6b0aee2`, `cccc03a`):
1. **Section 7.8 Optional LibreOffice Check**:
   - In `aab3c84`, `hiddenSofficeAction == nil` was replaced with `sofficeAvailable == false` because `FormatRegistry` statically registers actions with `requiredTool`.
   - **Restoration**: Added checks that `WheelLayoutModel.shared.slots` excludes `docx.to.pdf` when `soffice` is missing, and that invoking `OfficeTools.shared.convertOfficeToPDF` throws `PastaError.missingTool("soffice")`.
2. **Section 37.2 Vision OCR Test**:
   - In `aab3c84`, image width was increased from 500px to 800px to prevent text clipping; assertions on searchable PDF and rendered PDF OCR were loosened to check only `"PASTA"` or `"PASTA" && "OCR"`.
   - **Restoration**: Strengthened assertions to verify the full phrase `"PASTA"`, `"OCR"`, and `"2026"` across both searchable PDF invisible text extraction (`pdftotext`) and direct rendered PDF OCR.
3. **Section 37.2 Vision OCR Fallback Path**:
   - In `6b0aee2`, a `.fast` fallback without language correction was added to `performRecognition` for headless runners, but zero test assertions covered it.
   - **Restoration**: Added `forceFallbackToFast` and `didExecuteFallback` in `VisionOCRTools`, with a unit test proving that when accurate mode fails, the fallback executes and successfully recognizes text.
4. **Section 37.3 Watermark Tests**:
   - In `aab3c84`, diagonal watermark text was supplemented with an invisible horizontal text anchor for `pdftotext`. Other positions were untested.
   - **Restoration**: Added automated tests for `"center"` and `"top"` watermark positions, verifying `pdftotext` extraction for each position.
